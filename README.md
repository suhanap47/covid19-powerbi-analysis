# covid19-powerbi-analysis
COVID-19 Data Analysis Dashboard – Power BI

📌 Project Overview

This project analyzes COVID-19 data using Microsoft Power BI to understand the spread of the pandemic, total reported cases, deaths, and recovered cases across different countries and continents.

The interactive dashboard presents key COVID-19 indicators through KPI cards, bar charts, pie charts, and continent-based filters. It helps users explore the distribution of cases and compare the impact of COVID-19 across geographical regions.

🎯 Project Objectives

- Analyze total confirmed COVID-19 cases, deaths, and recovered cases.
- Identify countries with the highest number of reported cases.
- Compare deaths and recovered cases across countries.
- Explore COVID-19 cases across continents.
- Understand the proportion of recovered cases and deaths relative to total cases.
- Present important findings through an interactive Power BI dashboard.

📊 Dashboard Features

- KPI Cards: Display total confirmed cases, total deaths, and total recovered cases.
- Top 5 Countries by Cases: Highlights the countries with the highest reported case counts.
- Total Deaths by Country: Compares reported deaths across countries.
- Recovered Cases by Country: Shows the distribution of recovered cases.
- Continental Analysis: Allows users to filter the dashboard by continent.
- Top 3 Countries by Death Percentage: Compares the death percentage among selected countries.
- Recovery Percentage: Visualizes recovered cases as a proportion of total cases.
- Death Percentage: Visualizes reported deaths as a proportion of total cases.

🔍 Key Findings

Based on the current dashboard view:

1. High concentration of cases: The United States has the highest number of reported cases among the countries displayed.
2. Deaths across countries: The United States also has the highest reported death count among the countries shown.
3. Recovery trends: The United States accounts for the largest number of recovered cases among the displayed countries.
4. Geographical differences: The continent filter allows users to explore how reported cases vary across regions.
5. Case outcomes: The recovery and death percentage charts help compare reported outcomes against total confirmed cases.
6. Country-level comparisons: The dashboard makes it easier to identify differences in the reported impact of COVID-19 across countries.

Note: These findings reflect the current dashboard view and should be validated against the complete dataset. The rankings and percentages may change when filters are applied.
